 Overview

Toryabah Store is a premium front-end e-commerce website designed to provide users with a smooth shopping experience.

The project demonstrates modern UI/UX principles, responsive layouts, shopping cart functionality, wishlist management, product filtering, secure payment integration and email automation.

 Features
- Responsive Design
- Modern Navigation
- Product Search
- Category Filtering
- Shopping Cart
- Wishlist
- Product Modal
- Checkout System
- Paystack Payment Integration
- EmailJS Order Confirmation
- Downloadable Receipt (PDF)
- About Page
- Contact Page
- FAQ Section
- Google Maps Integration
- Newsletter Subscription
- Premium Footer
- Mobile Friendly

Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
- EmailJS
- Paystack API
- jsPDF
- Font Awesome
